# MVP 구현과 검증 범위

## 사용자가 확인할 수 있는 흐름

1. Oracle SQL/PLSQL 파일 또는 디렉터리를 CLI에 입력합니다.
2. 분석기가 객체, 직접/간접 컬럼 계보, 호출, 동적 SQL 진단을 JSON으로 출력합니다.
3. `web/index.html`의 왼쪽 객체 트리에서 테이블, 컬럼, PL/SQL 객체를 탐색합니다.
4. 가운데 테이블/뷰 노드 안의 컬럼별 그래프에서 계보를 확인합니다.
5. 선택한 객체의 소유 객체, 멤버, 입력/출력 관계와 표현식을 오른쪽 `Inspector`에서 확인합니다.
6. 검색과 관계 유형 필터로 영향 범위를 좁힙니다.

내장 데모가 첫 화면에 표시되므로 별도 서버 없이 UI를 먼저 확인할 수 있습니다.

## 분석 파이프라인

```text
Oracle SQL/PLSQL text
  -> literal/comment masking and balanced-range scanning
  -> schema and PL/SQL scope inventory
  -> query/CTE expression resolution
  -> semantic objects, relationships, diagnostics
  -> JSON
  -> static graph viewer
```

주요 구현:

- `OracleLineageAnalyzer`: 전체 분석 흐름과 DDL/DML/PLSQL 의미 추출
- `QueryAnalyzer`: CTE, 테이블 별칭, SELECT 출력식, 조건식의 컬럼 해소
- `SchemaCatalog`: 관계/컬럼 객체 인벤토리와 ID 일관성
- `FixtureVerifier`: 골든 기대값과 이름 치환 변형 검증
- `CorpusVerifier`: 공개/파서 코퍼스의 강건성, 커버리지, 엣지 무결성 검증
- `JsonWriter`: 정렬된 JSON 계약 출력
- `web/index.html`: 서버가 필요 없는 3패널 탐색기. 컬럼 객체는 테이블/뷰 노드의 행으로, 매개변수 객체는 프로시저/함수 노드의 행으로 투영하고 선택 객체의 관계를 `Inspector`에 표시

## 검증 기준

골든 픽스처는 객체, 관계, 진단의 실제 집합이 기대 집합과 정확히 일치하는지 확인합니다. 누락뿐 아니라 예상하지 않은 객체나 엣지도 실패입니다. 추가로 각 픽스처의 도메인 이름을 전혀 다른 이름으로 바꾼 뒤 기대값도 같은 방식으로 변환해 재검증합니다. 이 단계는 특정 샘플 이름을 조건문으로 처리하는 구현을 차단합니다.

공개 코퍼스 검증은 다음을 확인합니다.

- 고정된 SQL 파일 수 이상을 실제로 분석했는가
- 객체와 관계가 최소 커버리지 이상 생성되는가
- 테이블, 뷰, 패키지, 프로시저, 함수, 트리거와 직접/간접/호출 관계가 존재하는가
- 모든 관계의 소스와 타깃 ID가 `objects`에 존재하는가
- 개별 SQL 파일 분석이 예외로 중단되지 않는가

## 의도적인 한계

현재 의미 추출기는 Oracle 문법 전체를 생성형 파서로 파싱하지 않습니다. 다음 항목은 정확도 한계가 명확합니다.

- 다단계 중첩 서브쿼리와 복잡한 집합 연산
- 동의어, DB 링크, 실제 스키마 메타데이터를 사용한 객체 해소
- 패키지 오버로드 및 로컬/중첩 서브프로그램의 완전한 호출 해소
- `q'[...]'` 등 모든 Oracle 문자열 표기와 동적 PL/SQL 블록
- 커서, 루프, 예외 경로를 포함한 제어 흐름 기반 계보
- SQL 텍스트의 정확한 줄/열 위치

따라서 현재 결과는 파일 기반 사전 영향 분석과 기능 검증용입니다. 운영 수준 정확도를 주장하려면 다음 단계의 파서/AST 전환과 Oracle 실행 메타데이터 비교가 필요합니다.

## 다음 엔지니어링 단계

1. ANTLR PL/SQL 문법을 파서 경계로 도입합니다.
2. 파스 트리를 현재 의미 모델로 투영하는 AST 계층을 추가합니다.
3. 현재 `AnalysisResult` JSON 계약과 골든/변형 테스트를 유지합니다.
4. 소스 위치, 스키마 메타데이터, 동의어/DB 링크 해소를 추가합니다.
5. 동일 SQL을 Oracle에서 컴파일하고 참조 메타데이터와 비교하는 통합 검증을 추가합니다.
